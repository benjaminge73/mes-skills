# Sondes ChatGPT (jetables)

Ce dossier ne vit que sur la branche `chore/sonde-skill-chatgpt-vocal` et n'est jamais mergé.
Il vérifie si un skill installé depuis une marketplace GitHub est chargé par ChatGPT,
notamment en mode vocal Live. Une fois le résultat écrit, la PR est fermée et la branche supprimée.

Deux témoins : la phrase « El loro verde canta a medianoche. » (le `SKILL.md` est chargé)
et le mot « guacamole » (un fichier de `references/` est lu).
